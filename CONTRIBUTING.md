# Contributing

Ezriva is currently a solo hackathon entry owned by Kevin Cusnir. External
contributions are not accepted during the judged build unless the participation
model and disclosures are deliberately updated first.

Development work must follow `AGENTS.md`, the ordered checklist, conventional
commits, synthetic-data-only public testing, and the verification commands in
the README. Never add secrets, personal documents, or code from Kevin's earlier
projects.
