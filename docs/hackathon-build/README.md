# Public Build Documents

These documents are the public implementation contract for Ezriva:

1. `scope.md` controls feature cuts.
2. `prd.md` controls observable product behavior.
3. `brand-ux.md` controls identity, trust, and accessibility direction.
4. `spec.md` controls architecture and safety boundaries.
5. `checklist.md` controls execution order and verification pauses.

Private participant notes, source-document evidence, calendar schedules, local
workflow state, and authorization records are intentionally excluded from the
public repository. Their absence does not change the product contract above.
