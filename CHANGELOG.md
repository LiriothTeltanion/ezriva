# Changelog

All notable changes to Ezriva are documented here. Dates refer to verified
project increments; unreleased working-tree changes remain under `Unreleased`.

## Unreleased

### Added

- A repository start index, durable Codex handoff, and single build journal.
- Runtime fixture byte/dimension checks and regression coverage.
- Structured-output tests for invisible bidirectional control characters.

### Changed

- Moved the synthetic hero appointment to a stable future date for a useful
  reminder demo.
- Clarified that the local evaluation report retains no complete source while
  preserving a minimal synthetic hero review for Pause 1.
- Updated the pinned Pillow development dependency to 12.3.0.

### Security

- Reject bidirectional control characters introduced by untrusted model output.
- Restrict the hero review to expected, confirmed evidence fields.
