# Privacy

Ezriva uses synthetic data for all repository fixtures, screenshots, public
demos, and recorded material.

The MVP design does not persist raw uploaded documents. Later private/local
processing may hold source bytes only for the active request, after explicit
implementation and verification. Durable state is limited to normalized,
redacted action information needed for reminders and receipts.

Deleting Ezriva history cannot delete a calendar event that a user already
imported from an `.ics` file. The product must state that boundary clearly.
